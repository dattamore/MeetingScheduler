Designed a scalable and extensible Meeting Room Reservation Platform using low-level design principles 
🔹 No room can be double-booked in overlapping time slots 
🔹 Graceful failure for overlapping bookings 
🔹 Invalid time range validation (start ≥ end) 
🔹 Listing by Room or Employee 
🔹 Concurrency safety for simultaneous booking attempts
